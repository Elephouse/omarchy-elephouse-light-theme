# Elephouse Light

A light Omarchy theme drawn from [Elephouse](https://elephouse.de): warm paper, a dot-grid notebook, ink, and a red accent.

```sh
omarchy theme install https://github.com/Elephouse/omarchy-elephouse-light-theme.git
omarchy hook install theme-set ~/.config/omarchy/themes/elephouse-light/hooks/elephouse-brand
bash ~/.config/omarchy/hooks/theme-set.d/elephouse-brand elephouse-light
```

The hook puts the elephant on About, the screensaver, fastfetch, and the menu button. Later theme changes apply it on their own.
